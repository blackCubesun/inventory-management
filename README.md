# Система управления товарными запасами

Информационно-аналитическая база для управления запасами на 22 СТО.

## Структура проекта

- `data/raw/` — исходные файлы из 1С
- `data/processed/` — нормализованные данные и модель
- `scripts/` — код обработки
- `output/` — результаты

## Как использовать

1. Поместить выгрузки из 1С в `data/raw/`
2. Запустить нормализацию:
py scripts/normalize_all.py

text
3. Запустить модель:
py scripts/model.py

text

## Результат

- Остатки по СТО
- Зоны: Крит, Норма, Избыток, Неликвид
- ABC-классификация по стоимости
- XYZ-классификация по стабильности спроса
- Рекомендации по перемещению

## Технологии

- Python 3.14
- pandas
- openpyxl
